# PowerShell IT Admin Toolkit

Practical PowerShell scripts for IT infrastructure administration, monitoring and troubleshooting.

This repository provides scripts for:

- Windows Server
- VMware
- Hyper-V
- Azure
- Microsoft Azure Backup Server (MABS)
- Infrastructure automation

## TechRunbook
